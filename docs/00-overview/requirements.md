# 요구사항 정의

## 1. 기능 요구사항

| ID | 도메인 | 요구사항 | 우선순위 |
|---|---|---|---|
| FR-01 | user | 이메일/비밀번호 회원가입, JWT 로그인 | P0 |
| FR-02 | asset | 연동 계좌/카드 자산 목록 조회 (Mock 마이데이터) | P1 |
| FR-03 | point | 포인트 잔액 조회, 거래 내역 조회 | P0 |
| FR-04 | point | 포인트 사용/환불 (원장 기반, 이중 반영 방지) | P0 |
| FR-05 | event | 출석체크 (1일 1회, 중복 지급 금지) | P0 |
| FR-06 | event | 퀴즈 정답 시 선착순 N명 포인트 지급 | P0 |
| FR-07 | event | 대기열 진입/순번 조회 (폭주 시) | P1 |
| FR-08 | cs | 공지사항, 1:1 문의 게시판 | P2 |
| FR-09 | 공통 | DR 모드 시 이벤트 API는 점검 응답(503 + 안내) 반환 | P0 |

## 2. 비기능 요구사항

| ID | 분류 | 요구사항 | 목표 |
|---|---|---|---|
| NFR-01 | 성능 | 이벤트 피크 처리량 | 5,000 RPS 이상 (부하테스트 기준) |
| NFR-02 | 성능 | 이벤트 API p95 응답 시간 | < 500ms |
| NFR-03 | 확장성 | 이벤트 시작 전 사전 확장 | 시작 5분 전 목표 레플리카 확보 |
| NFR-04 | 가용성 | Main 환경 | Multi-AZ, 단일 AZ 장애 무중단 |
| NFR-05 | DR | 리전 장애 복구 시간 | RTO ≤ 30분 |
| NFR-06 | DR | 데이터 유실 허용 범위 | RPO ≤ 5초 (CDC Lag p99) |
| NFR-07 | 정합성 | 포인트 이중 지급/이중 차감 | 0건 (멱등키 + 유니크 제약) |
| NFR-08 | 보안 | 저장 데이터 암호화 | KMS / CMEK 적용 |
| NFR-09 | 보안 | 전송 구간 암호화 | TLS 1.2+, 클라우드 간 HA VPN |
| NFR-10 | 운영 | 인프라 변경 | 100% Terraform, 콘솔 수동 변경 금지 |
| NFR-11 | 비용 | DR 평시 비용 | 컴퓨팅 0, DB/네트워크만 유지 |

## 3. 규제·컴플라이언스 고려사항 (학습 목적 정리)

> 아래는 설계 근거로 참고한 항목이며, 실제 적용 시 최신 법령과 감독규정 원문 확인이 필요하다.

| 항목 | 설계 반영 |
|---|---|
| 전자금융거래법 / 전자금융감독규정 (재해복구, 업무연속성) | DR 환경 구축, 정기 DR 훈련 계획, 복구 목표 시간 명시 |
| 선불전자지급수단 성격의 포인트 | 잔액·원장 데이터 실시간 복제 대상 지정, 이중 반영 방지 |
| 개인정보보호법 / 신용정보법 (마이데이터) | 개인정보 컬럼 암호화, 접근 로그, 최소 권한 |
| 망분리 / 내부망 원칙 | 데이터 계층 Private Subnet, VPC Endpoint, 클라우드 간 사설 경로 |
